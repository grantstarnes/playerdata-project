// SYSTEM SETUP GUIDE

HP Victus 15 → Linux Dev Server

Ubuntu 24.04 LTS · CUDA · Ollama · Tailscale · systemd services
Machine HP Victus 15
GPU RTX 3060 Mobile · 6GB VRAM
RAM 16 GB
CPU AMD Ryzen
Target OS Ubuntu 24.04 LTS
00 Before You Start ~15 min prep
Download Ubuntu 24.04 LTS Server ISO
Get the server ISO (not Desktop). Smaller, no GUI overhead, better for headless operation.
# Download from: https://ubuntu.com/download/server
# File: ubuntu-24.04.x-live-server-amd64.iso (~2.5GB)
If you want a GUI fallback (easier first-time setup), grab Ubuntu Desktop 24.04 instead. You can always disable the GUI later.
Flash USB Drive
Use Balena Etcher (Windows/Mac) or Rufus (Windows) to flash the ISO to a USB drive (8GB+).
# Balena Etcher: https://etcher.balena.io — just click through, 5 minutes
BIOS: Disable Secure Boot, Set Boot Order
Restart the Victus, tap F10 or Esc repeatedly to enter BIOS. Disable Secure Boot (causes NVIDIA driver issues). Set USB as first boot device.
HP Victus BIOS key is usually F10 for setup or Esc → F9 for boot menu.
01 OS Installation ~20 min
Boot from USB and Install Ubuntu Server
Follow the installer. Key choices to make:
# Network: connect to WiFi or ethernet during install
# Storage: "Use entire disk" — wipe the old Windows install
# Profile: set username, password, hostname (e.g. victus-server)
# SSH: CHECK "Install OpenSSH server" — essential for remote access
# Snaps: skip all optional snaps for now
First Boot: Update Everything
After login, run a full system update before touching anything else.
$sudo apt update && sudo apt upgrade -y
$sudo reboot
Install Essential Packages
Baseline tools you will need throughout the rest of setup.
$sudo apt install -y curl wget git build-essential htop net-tools ufw python3 python3-pip python3-venv
02 NVIDIA Drivers + CUDA ~20 min
Install NVIDIA Drivers via ubuntu-drivers
Ubuntu's driver manager detects the 3060 and installs the recommended driver automatically. Easiest path.
$sudo ubuntu-drivers autoinstall
$sudo reboot
Verify Driver Installation
After reboot, confirm the GPU is recognized.
$nvidia-smi
# Should show: RTX 3060, driver version, CUDA version
If nvidia-smi returns "command not found", the driver install failed. Run: sudo apt install nvidia-driver-535 manually then reboot.
Install CUDA Toolkit
Ollama handles most GPU work itself, but installing the CUDA toolkit gives you nvcc and lets other tools use the GPU too.
$sudo apt install -y nvidia-cuda-toolkit
$nvcc --version
# Should print CUDA compilation tools version
Ollama bundles its own CUDA runtime so even if nvcc shows an older version, Ollama will still use full GPU. This install is just for other tools.
03 Network Configuration ~15 min
Assign a Static Local IP
Prevents the laptop IP from changing on router restarts. Do this in your router admin panel (easier) or via Netplan on the server. Router method recommended: find the Victus MAC address, assign a fixed IP like 192.168.1.100.
$ip a
# Note the MAC address of your network interface (eth0 or wlan0)
# Go to router admin (usually 192.168.1.1) → DHCP → Assign static IP to MAC
Configure UFW Firewall
Enable firewall, allow SSH and your app ports. Keep it tight.
$sudo ufw allow OpenSSH
$sudo ufw allow 8000 # FastAPI
$sudo ufw allow 11434 # Ollama
$sudo ufw enable
$sudo ufw status
Install Tailscale
Gives the server a permanent private IP (100.x.x.x) reachable from anywhere. Works through firewalls and NAT. Free for personal use.
$curl -fsSL https://tailscale.com/install.sh | sh
$sudo tailscale up
# Opens a browser auth URL — log in with your Tailscale account
$tailscale ip -4
# Note this 100.x.x.x IP — this is your permanent server address
Install Tailscale on your main machine and phone too. You'll be able to SSH into the Victus from anywhere using the 100.x.x.x address.
Configure SSH for Key-Based Auth (optional but recommended)
Copy your main machine's SSH public key to the server for passwordless login.
# Run this from your MAIN machine, not the server:
$ssh-copy-id raj@192.168.1.100
# Then test: ssh raj@192.168.1.100
04 Ollama Setup ~10 min + model download
Install Ollama
Official install script handles everything: binary, CUDA detection, and systemd service registration.
$curl -fsSL https://ollama.com/install.sh | sh
# Installs to /usr/local/bin/ollama
# Registers ollama.service automatically
Pull Gemma 3 4B and Verify GPU Usage
Pull the model, then confirm it's running on the 3060 not CPU.
$ollama pull gemma3:4b
# ~3.3GB download, one time only
$ollama run gemma3:4b "hello"
# In a second terminal while model is running:
$ollama ps
# Should show: gemma3:4b ... GPU: 100% (or partial)
Expose Ollama on Network (for FastAPI to reach it)
By default Ollama only listens on localhost. Override this so FastAPI running elsewhere can reach it, and so your main machine can too via Tailscale.
$sudo systemctl edit ollama.service
# Add these lines in the editor:
# [Service]
# Environment="OLLAMA_HOST=0.0.0.0"
$sudo systemctl daemon-reload && sudo systemctl restart ollama
Exposing Ollama on 0.0.0.0 is fine on your home network + Tailscale. Don't do this on a public-facing machine without auth in front of it.
05 FastAPI as a systemd Service ~15 min
Set Up Python Environment for Your App
Clone your repo and create a venv. Keep it isolated.
$git clone https://github.com/yourrepo/playerdata-api.git ~/apps/playerdata
$cd ~/apps/playerdata
$python3 -m venv .venv
$source .venv/bin/activate
$pip install -r requirements.txt
Create systemd Service File
Makes FastAPI start on boot and restart on crash automatically.
$sudo nano /etc/systemd/system/playerdata.service
# Paste the following:
#
# [Unit]
# Description=PlayerData FastAPI
# After=network.target ollama.service
#
# [Service]
# User=raj
# WorkingDirectory=/home/raj/apps/playerdata
# ExecStart=/home/raj/apps/playerdata/.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
# Restart=always
#
# [Install]
# WantedBy=multi-user.target
$sudo systemctl daemon-reload
$sudo systemctl enable playerdata
$sudo systemctl start playerdata
$sudo systemctl status playerdata
Test the Stack End-to-End
Verify FastAPI is reachable and can talk to Ollama.
# From the server itself:
$curl http://localhost:8000/health
$curl http://localhost:11434/api/tags
# From your main machine (replace with Tailscale IP):
$curl http://100.x.x.x:8000/health
06 Quality of Life ~10 min
Prevent Sleep / Lid-Close Suspend
Ubuntu Server suspends on lid close by default. Disable this so it keeps running when the laptop lid is shut.
$sudo nano /etc/systemd/logind.conf
# Set these lines (uncomment if commented):
# HandleLidSwitch=ignore
# HandleLidSwitchExternalPower=ignore
$sudo systemctl restart systemd-logind
Set Up Unattended Upgrades (Security Patches)
Auto-applies security updates silently. Set it and forget it.
$sudo apt install unattended-upgrades -y
$sudo dpkg-reconfigure --priority=low unattended-upgrades
# Select "Yes" when prompted
Add SSH Config on Main Machine
Makes SSH to the server a single short command instead of typing the full address.
# On your main machine, add to ~/.ssh/config:
# Host victus
# HostName 100.x.x.x ← Tailscale IP
# User raj
# IdentityFile ~/.ssh/id_ed25519
#
# Then just: ssh victus
